# guessinggame
Guessing Game inspired by seJma. 

The inspiration I got, was enough to want to test and play around with batchfiles, I learned a lot of fundamentals about coding in these early years.
While the original game was in English, I decided to use Estonian, my native-language after all.
It was made while finding an easy solution to finalise the project as a school assignment that we didn't really want to do back in the day.
Coded and experimented this with two of my old friends.
